# Abstract

VERIFORGE 1.0.0 checks four arithmetic identities, x+0, x-0, x*1, and x*0, with the Z3 solver. Expressions use either mathematical integers or unsigned fixed-width bit vectors. This work did not change the version number. It added a second parser, a second concrete evaluator, a polynomial identity test for integers, and an exhaustive check for bit vectors whose full assignment space is at most 65,536. A 463-pair dataset in 27 families was frozen before scoring. The protocol hash was recorded at 2026-10-11 16:43:36 UTC. The older eight-case held-out file was kept. The execution host could not install Z3, CVC5, or Bitwuzla, so no solver comparison is reported and the primary solver hypothesis is inconclusive. On 54 held-out non-equivalent pairs, boundary and random testing missed zero bugs at input budgets of 10, 100, 1,000, and 10,000. The 95 percent Wilson upper bound on that zero-over-54 rate is 0.066. Because the miss rate did not fall, the preregistered claim that the larger budget detects more bugs is not supported. False alarms on 64 equivalent pairs were also zero. Sixteen pairs were valid in one semantic mode and invalid in the other. Ten seeded faults were all detected on fixed fixtures. Shorter expressions are not reported as faster programs. The historical eight-case set was not mixed into these scores. The study applies known translation-validation and differential-testing ideas to a small grammar. It does not claim a new decision procedure.
